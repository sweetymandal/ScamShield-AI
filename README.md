# ScamShield AI

An AI-powered web application for detecting online scams, phishing messages, and suspicious URLs.

## Project Structure

```text
ScamShield-AI/
├── app.py
├── requirements.txt
├── README.md
├── templates/
│   ├── index.html
│   ├── analyzer.html
│   └── dashboard.html
├── static/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── script.js
├── models/
│   ├── __init__.py
│   └── scam_model.py
└── database/
    ├── __init__.py
    ├── db_manager.py
    └── database.db
```

## Quickstart

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run application:
   ```bash
   python app.py
   ```
3. Open browser at `http://127.0.0.1:5000`
